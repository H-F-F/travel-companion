# AI Travel Companion

基于当天天气的智能旅行管家，提供“天气分析 + 景点推荐 + AI 路线规划 + 美食推荐”四合一能力。

## 核心价值
- 天气驱动：根据实时天气与预报动态调整建议。
- 一体化推荐：不再分开查天气、景点、路线和吃饭地点。
- 可执行行程：考虑营业时间、交通时长、预算和天气风险。
- 动态重规划：遇到下雨、封馆、拥堵时快速给替代方案。

## 主要功能
1. 天气分析：温度、降雨、风力、体感、出行提示。
2. 景点推荐：按天气适配、热度、时段、预算排序。
3. 景点分类：支持人文景点 / 自然景观 / 城市地标 / 室内场馆偏好。
4. 路线规划：生成 1 日 / 3 日可执行行程。
5. 美食推荐：结合口味、预算、距离、营业状态推荐。
6. 选择式规划：在景点推荐 / 美食推荐中直接标记“想去 / 想吃 / 不感兴趣”后重生成。
7. 过程反馈：生成计划时展示弹窗、阶段文案和进度条。
8. 铁路票务：支持记录预定日期、出发城市 / 车站，并通过 12306 MCP 查询车站、直达票和中转方案。

## 快速运行后端原型
```powershell
python -m backend.simple_server
```

接口：
- `GET /health`
- `GET /api/v1/locate?lat=<纬度>&lon=<经度>`
- `GET /api/v1/geocode?address=<地址>&city=<城市可选>`
- `GET /api/v1/weather?address=<地址或城市>&days=3`
- `GET /api/v1/search-address?q=<关键词>&limit=12`
- `GET /api/v1/transport/stations?q=<车站关键词>&limit=8`
- `POST /api/v1/plan`

`POST /api/v1/plan` 新增支持字段：
- `planning_mode`：`auto` / `candidate`
- `booking_date`
- `origin_city`
- `origin_station`
- `attraction_styles`
- `selected_attractions` / `excluded_attractions`
- `selected_foods` / `excluded_foods`

前端页面：
- 启动后访问 `http://127.0.0.1:8000/`
- 参数页已改为三步引导式布局，默认预设 3 天、标准预算，可先一键生成再微调。
- 页面支持“选择地址”按钮，搜索后单选并点击“应用所选地址”即可覆盖默认定位地址。
- 城市输入框现在支持直接输入城市、区县或详细地址，后端会优先解析成经纬度。
- 切换城市或地址后会自动刷新天气面板，固定显示未来 3 天。
- 参数页新增景点偏好选项，可勾选人文景点 / 自然景观 / 城市地标 / 室内场馆。
- 景点偏好与口味偏好已升级为带图标的卡片式选项，结果页路线改为时间轴卡片展示。
- 结果页景点推荐支持按分类切换，并按页浏览当前推荐结果。
- 美食推荐已支持分页浏览；景点 / 美食推荐区可直接勾选偏好后重新生成路线。
- 结果页新增高德 POI 搜索栏，支持按“搜景点 / 搜美食”搜索附近结果；景点搜索会按高德 `typecode` 自动分组为人文 / 自然 / 城市休闲等分类展示。
- 当前可填写预定日期、出发城市与出发车站；配置 `MCP_12306_URL` 后会在生成方案时自动查询 12306 直达和中转方案。

高德地图接入（推荐）：
```powershell
$env:AMAP_API_KEY="你的高德Web服务Key"
python -m backend.simple_server
```
说明：配置后将优先使用高德接口获取位置、距离和天气。

也可以直接写到项目根目录 `.env`（已被 `.gitignore` 忽略）：
```env
AMAP_API_KEY=your_amap_web_key
MCP_12306_URL=http://127.0.0.1:8001/mcp
AMAP_NEAREST_RAIL_FIRST=0
```

12306 MCP 接入（可选）：
```powershell
$env:MCP_12306_URL="http://127.0.0.1:8001/mcp"
python -m backend.simple_server
```
说明：建议把 12306 MCP Server 映射到 `8001` 等独立端口，避免与本项目默认的 `8000` 端口冲突。
如果项目根目录下存在本地安装的 `.mcp12306/node_modules/12306-mcp`，后端也会自动优先走本地 `stdio` 方式调用，不强依赖 `MCP_12306_URL`。

地理编码示例：
```powershell
curl "http://127.0.0.1:8000/api/v1/geocode?address=汉中&city=汉中"
```

天气预报示例：
```powershell
curl "http://127.0.0.1:8000/api/v1/weather?address=汉中&days=3"
```

## 自动更新机制
项目已提供事件驱动文档同步脚本：`scripts/Sync-ProjectDocs.ps1`

### 可触发事件
- 立项创建
- 需求变更
- 任务状态变化
- 技术决策
- 风险识别
- 问题关闭
- 版本发布

### 使用示例
```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Sync-ProjectDocs.ps1 -Event 需求变更 -Detail "新增雨天室内路线策略"
```

## 当前状态
- 零依赖后端原型与 FastAPI 双入口均可用。
- 已支持地理编码、逆地理编码、地址搜索、独立天气查询、候选项多选与路线规划。
- 前端已支持地址切换后自动刷新 3 日天气，并可在结果页按候选项二次重生成路线。
- 已支持景点偏好选择、景点分类标签和分页浏览。
- 已支持 12306 车站搜索、余票与中转查询；未配置 `MCP_12306_URL` 时会自动降级为仅生成本地路线。
